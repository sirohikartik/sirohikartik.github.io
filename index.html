Projects

tinyGPT — C++, Python, PyTorch, Transformer

End-to-end GPT training and inference engine. A 30M-parameter decoder-only model trained on TinyStories, paired with a native C++ inference engine implementing multi-head attention, LayerNorm, KV caching, and ARM NEON SIMD-optimized tiled matrix multiplication with OpenMP parallelism (14.08ms TTFT, 8.11ms/token, ~121 tok/s on M1 CPU). Later ported the NEON kernels to SSE instructions and deployed the engine on a free Render instance, now running live at roughly 5–7 tok/s.

Live demo ↗ GitHub ↗ Write-up ↗ Docs ↗

mini-torch — Python, Autograd

Minimal deep learning framework built from first principles. Reverse-mode automatic differentiation over a dynamic computation graph, gradient accumulation, SGD+momentum and Adam optimizers, training MLPs to approximate continuous functions.

GitHub ↗

Docs ↗

Rocky — Python, LLM Agents, Sentence-BERT, Whisper API

Real-time speech-to-Indian Sign Language translation engine. Chunked Whisper transcription feeds a dual-stage vocabulary resolver (exact lookup → Sentence-BERT similarity matching), while a closed-loop LLM grammar agent enforces ISL structure (topic–comment order, time-first ordering) constrained to the resolved vocabulary to avoid hallucinated signs. Output renders as stitched video or 3D avatar rotation data.

GitHub ↗

Athena — Python, FAISS, Ollama, RAG

Privacy-preserving local RAG search agent. Concurrent web scraping, dense embedding generation via Sentence Transformers, FAISS-based semantic retrieval, and source-grounded generation using locally hosted LLMs.

GitHub ↗

Linear Algebra Engine — C++, pybind11

C++ linear algebra library with Python bindings. Gaussian elimination, Gauss–Jordan inversion, cache-friendly blocked matrix multiplication, and determinant computation, exposed to Python through pybind11.
