EPSE — Efficient Protein Search Engine

C • Information Retrieval • Bioinformatics • Systems Engineering

EPSE is an experimental protein database search engine designed for resource-constrained environments. Rather than loading every protein embedding into memory, EPSE organizes proteins into clusters and only loads the most relevant partitions during retrieval, dramatically reducing memory requirements.

GitHub Website Documentation
  • Built in C for efficient execution and memory usage.
  • Protein embeddings generated using ESM-2 (35M parameter model).
  • Clustering-based retrieval using cosine similarity.
  • Disk-backed embedding storage to reduce RAM consumption.
  • Focused on large-scale biological sequence search.
  • Search pipeline currently under active development.

tinyGPT

C++ • Transformers • SIMD • High Performance Computing

A custom transformer inference engine written from scratch for running a 30 million parameter TinyStories language model. Features SIMD-optimized matrix multiplication and cache-aware execution.

GitHub
  • Complete decoder-only transformer implementation.
  • GPT-2 compatible byte pair encoding tokenizer.
  • SIMD accelerated matrix multiplication using AVX and NEON.
  • Cache-aware tiled kernels for improved memory locality.
  • 96.9ms Time-to-First-Token on Apple M1 Air.
  • 1.88 tokens/sec generation throughput.

Mini-Torch

Python • Deep Learning • Automatic Differentiation

A minimal deep learning framework built from scratch to understand the internals of modern machine learning libraries. Includes automatic differentiation, optimization, and neural network training.

GitHub Documentation
  • Custom Tensor implementation.
  • Reverse-mode automatic differentiation.
  • Dynamic computation graph.
  • Gradient accumulation and backpropagation.
  • SGD and Adam optimizers.
  • End-to-end neural network training support.

Athena

Python • Retrieval • Search • Local LLMs

Athena is an open-source search agent that combines web search, intelligent scraping, semantic retrieval, and local language models to answer questions using current information from the web.

GitHub
  • DuckDuckGo-powered search pipeline.
  • Hybrid scraping using requests and Selenium.
  • Semantic retrieval using sentence-transformers and FAISS.
  • Local LLM inference through Ollama.
  • Source attribution and citation support.
  • Privacy-first design with local processing.
